# PREDICTA AI — Agent Instructions

## 1. PROJECT

PREDICTA AI is a premium AI-powered sports analytics platform.

The platform analyzes sporting events and produces statistical predictions and probability estimates.

Supported sports:

- Football
- Basketball
- Tennis

The product is a sports intelligence platform, NOT a bookmaker.

The system must never claim that a prediction is guaranteed.

Predictions represent statistical probabilities generated by models.

# 6. AI SAFETY AND DATA INTEGRITY

Never fabricate:

- Odds
- Statistics
- Injuries
- Player availability
- Lineups
- Match results
- Team form
- League standings
- Historical data
- Prediction performance

If data is unavailable, explicitly indicate that the data is unavailable.

Never present invented data as real data.

Mock data may be used during development, but it must be clearly separated from production data.

---

# 7. PREDICTIONS

Predictions must always be expressed as probabilities or model signals.

Example:

GOOD:

"Model probability: 68%"

"Model confidence: High"

"Estimated edge: +7.2%"

BAD:

"This team will definitely win."

"Guaranteed bet."

"Safe bet."

"100% sure."

Never promise financial returns.

---

# 8. VALUE BETTING

The Value Engine should eventually calculate:

Implied Probability:

1 / odds

Edge:

model_probability - implied_probability

Expected Value:

(model_probability × odds) - 1

The system should also consider bookmaker margin / overround where appropriate.

All calculations must be transparent and reproducible.

---
